CLI Commands

Command Description & Flags
greenprofiler init
alias: gp init
 Generate greenprofiler.json and discover application routes automatically.
[--force] [--filter <k>] [--exclude <k>]
greenprofiler run
alias: gp run
 Execute process-level CPU energy profiling, calibrated code audit, and multi-user simulation.
[greenprofiler.json] [--strict] [--users <n>] [--no-open] [--filter <k>] [--exclude <k>] [--output <path>]
greenprofiler analyze
alias: gp analyze
 Run calibrated static code quality inspection (NCLOC, CCN, MI, Control-Flow Smells) & Native PHP Extension candidate detection.
[dir] [--strict] [--users <n>] [--no-open] [--filter <k>] [--exclude <k>] [--output <path>]
greenprofiler simulate
alias: gp simulate • gp sim
 Simulate multi-user concurrency load, CPU core saturation, P95 queueing latency, monthly kWh, and CO2e from existing audit JSON.
[report.json] [--users <n>] [--rpu <n>] [--cores <c>] [--window <sec>] [--no-open] [--output <path>]
greenprofiler routes
alias: gp routes
 Discover and list application endpoints directly from source code across fullstack monorepos.
[dir] [--limit <n>] [--filter <k>] [--exclude <k>]
greenprofiler detect
alias: gp detect
 Audit PHP Green Extensions (OPcache, JIT, Xdebug) and scan active server PIDs.
greenprofiler ui
alias: gp ui
 Open the latest generated HTML audit or simulation dashboard in your default browser.
