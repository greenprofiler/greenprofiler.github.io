01 / DISCOVERY

Framework Agnostic

Auto-detects routes without limits across Next.js, Laravel, FastAPI, Go, and Axum with greenprofiler init.

02 / BENCHMARK

Pure CPU Energy

Isolates kernel execution times from database wait and network I/O bias to measure real Joules & carbon output.

03 / AUDIT

Quality & Runtime

Inspects Cyclomatic Complexity, Maintainability Index, code smells, and PHP OPcache/JIT energy impact.

CLI Commands
greenprofiler <cmd> • gp <cmd>
Command Description & Flags
greenprofiler init
alias: gp init
 Initialize configuration and scan application routes automatically.
[--force] [--filter <k>] [--exclude <k>]
greenprofiler run
alias: gp run
 Execute full process-level energy profiling and code quality audit.
[config.json] [--no-open] [--filter <k>] [--exclude <k>] [--output <path>]
greenprofiler analyze
alias: gp analyze
 Run static code quality analysis (NCLOC, CCN, MI, Smells) without running server transactions.
[dir] [--no-open] [--filter <k>] [--exclude <k>] [--output <path>]
greenprofiler routes
alias: gp routes
 Discover and display real application endpoints directly from source code.
[dir] [--limit <n>] [--filter <k>] [--exclude <k>]
greenprofiler detect
alias: gp detect
 Scan and display active web server background processes and their Process IDs (PID).
greenprofiler ui
alias: gp ui
 Open the latest generated HTML audit report dashboard in your default browser.
